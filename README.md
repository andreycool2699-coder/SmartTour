SmartTour
Проект предназначен для аналитики отзывов из интернет-сообществ.
В проекте работает telegram-бот, который позволяет получать информацию о туристических маршрутах
и собирать данные для аналитики. Бот работает на основе модели ChatGPT и GigaChat.

Для проекта разрабатываются мобильные приложения для планирования туристических маршрутов по разным городам России
